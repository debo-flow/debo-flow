## `01 //` About Me

I am an independent developer focused on **scientific computing**, **computational physics**, **mathematics**, and **software engineering**. My work centers on translating mathematical formulations and physical models into interactive computational laboratories, numerical simulations, and practical software tools.

```yaml
developer:
  name: "Deborudra De"
  handle: "@debo-flow"
  focus_areas:
    - Scientific Computing & Numerical Methods
    - Computational Physics (Electromagnetics, Relativity, Nonlinear Dynamics)
    - Symbolic & Computational Mathematics (Calculus, Linear Algebra, Complex Analysis)
    - Applied Cryptography & Post-Quantum Security Simulations
    - Digital Signal Processing, Code Analysis & Interactive Web Applications
  methodology:
    - Translating differential equations and mathematical structures into clean code
    - Building interactive visual laboratories for exploring complex systems
    - Designing modular, reproducible, and self-contained software architectures
```

- **Scientific Computing & Numerical Methods:** Implementing finite-difference schemes, ODE/PDE solvers, symbolic engines, and high-dimensional visualizations.
- **Computational Physics & Mathematics:** Exploring Schwarzschild spacetime geometry, 3D FDTD electromagnetics, damped/driven nonlinear oscillators, complex fractals, linear algebra, and calculus.
- **Cryptography & Security Engineering:** Developing laboratories and tools for symmetric/asymmetric encryption (AES, RSA), Quantum Key Distribution (QKD), hybrid post-quantum key encapsulation, client-side password management, and JavaScript AST analysis/obfuscation.
- **Interactive Software Systems:** Building responsive scientific applications and browser-based developer tools using Python, Streamlit, JavaScript, TypeScript, HTML, and CSS.
